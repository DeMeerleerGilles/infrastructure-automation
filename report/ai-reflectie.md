# AI reflectie

Welke tool(s) heb je gebruikt en op welke manier? Geef voorbeelden van prompts en output.

Ik heb voornamelijk gebruik gemaakt van ChatGPT en Github copilot. Soms ook Gemini met het gratis pro abonnement voor school. ChatGPT is volgens mijn ervaring het meest geschikt voor het genereren van scripts. Het is wel belangrijk om heel specifiek te zijn in je prompt.

## Voorbeelden van prompts:

- Geef mij een ansible playbook voor het opzetten van een DNS server
- Ik krijg deze ... error bij het uitvoeren van de volgende code: ...
- Kun je mij op basis van deze requirements een ansible playbook genereren? Dit is de laatste documentatie van de rol: ...

Wat was in de context van dit vak jouw grootste succes met het gebruik van AI-tools?

Troubleshooten van code was voor mij het grootste succes. Ik gebruikte AI-tools om fouten in mijn code te identificeren en suggesties te krijgen voor oplossingen. Zelf kan je soms heel lang zitten zoeken naar een fout, maar AI kan vaak snel de mogelijke oorzaken aangeven.

Wat was de grootste teleurstelling? Wanneer heeft een AI-tool jou niet geholpen of wanneer heeft het je een totaal foute oplossing voorgesteld? Geef voorbeelden van prompts en output.

Soms gaf ChatGPT of Copilot een oplossing die eerst juist leek, maar in de praktijk niet werkte vanwege verouderde verwijzingen of onjuiste assumpties over de omgeving. Hierop zit je dan heel lang te zoeken naar de juiste oplossing.

Waar ga je in de toekomst zeker op letten wanneer je AI-tools gebruikt bij het uitvoeren van je job?

Minder snel vertrouwen op de eerste output van een AI-tool. Zelf ook de documentatie blijven raadplegen en de gegenereerde code grondig testen.

Zijn er aspecten in de opdracht die je door het gebruik van AI-tools als "te makkelijk" ervaren hebt? Zou je zaken veranderen aan de opdracht zodat die meer aangepast is aan het nieuwe "AI-tijdperk"?

Eigenlijk niet, AI kan zeker helpen bij het genereren van de basis van scripts, maar vaak zijn er toch nog grote aanpassingen nodig om het echt bruikbaar te maken. Dit komt omdat een AI script zelden foutloos uitgevoerd worden (tenzij het heel simpel is).
